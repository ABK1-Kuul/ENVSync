# Definition of Done

A task is done only when:
- [ ] Acceptance criteria are met.
- [ ] Relevant tests were added/updated.
- [ ] Relevant checks were run and results reported honestly.
- [ ] No real secret values are present in code, logs, fixtures or generated files.
- [ ] Target project code is not executed during scanning.
- [ ] Existing files are preserved unless an approved write is required.
- [ ] Diagnostics and JSON output are consistent.
- [ ] Documentation/examples reflect actual behavior.
- [ ] Scope remained focused; deferred work is listed explicitly.
